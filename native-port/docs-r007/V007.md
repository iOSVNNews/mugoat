# MuLone-V007 corrective release

Evidence: user A16 log, V006, lowest preset 936x432, unlimited FPS. 33 health samples: initially 60 FPS/fair, later 39–49 FPS/serious. The old GPU field was 0.7–3.5 ms PER COMMAND BUFFER, mislabeled as frame time; 15–22 buffers/frame mean it cannot establish low GPU utilization. CPU grows to ~2.7 core equivalents. Menyoo active (~0.8–2.2 ms average per frame). Late memory guard holds at 448–472 MiB free but zero eviction requests; not evidence for making memory reserves smaller. Pipeline skips exist; no claim that compilation stutter is eliminated.

Confirmed translation defect: `pg_mods_for_archive` silently returned only the first 256 pieces from each archive, while each bundled language archive supplies 608 dictionaries. Log showed only 252 of 256 applied. Prior importer/package tests did not exercise this runtime handoff. Replaced TLS scratch array with complete immutable per-archive arrays, allocated once at startup. Stable across nested lookups. All entries can now be offered to the engine; missing base entries are still skipped, not fabricated. Added explicit bounded `global.gxt2` patch diagnostic.

Reduced informational logging before fprintf/mutex/UI callback: cutscene-time traces and native hash insertion diagnostics are counted/sampled; repeated audio-stall warnings keep initial and logarithmic samples. Other warnings/errors, memory and health diagnostics remain. Verbose mode PG_VERBOSE_LOGS=1 restores traces. Individual overlay setup prints bounded examples plus complete counts instead of consuming the early log buffer.

One-time V007 baseline: unlocked changes to 60 FPS, built-in Menyoo disabled. Users can re-enable both afterward. Existing 30 FPS choices and graphics quality remain untouched. HUD polling explicitly capped at 60 Hz when not unlocked; controller/HUD no longer requests 120 Hz for the baseline. No rendering, PSO cache, audio synchronization or memory-guard algorithm changes. GPU diagnostics now sum completed command-buffer durations and divide by completed presents; regression test covers a 20-buffer/20-ms frame that the old counter would report as 1 ms. This is summed GPU work, not a full CPU/GPU timeline.

Regression tests extract the actual production archive lookup and verify all 608 entries, global beyond index 256, stable pointers across archives, aliases and case. Log classification checks preserve errors and other warnings. Existing full mod/sound/save and translation tests retained. Gameplay and sustained FPS still need device testing; thermal status suggests heat pressure, but the log does not measure CPU frequency or prove one cause for all drops.
