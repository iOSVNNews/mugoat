# MuLone-V006

## Changes
- Fresh installs default to Lite (or Battery if Lite is unavailable). Existing graphics choices remain intact.
- Engine virtual reservation follows the 1.4.7 binary policy: process budget >=5120 MiB permits min(budget-1024,7168) MiB, otherwise 4095 MiB. Existing process/heap/streaming guards, memory cap and reservation fallbacks remain. This does not grant iOS permissions or allocate that amount of physical RAM immediately.
- Script coroutines preserve their PC when they exceed a slice (20M first, 8M subsequent instructions), with a 3B-instruction runaway cap between explicit waits; callbacks retain a bounded limit. Policy recovered from 1.4.7, not its renderer.
- Multi-select loose vehicle files, stock vehicle metadata fallback when the runtime index is incomplete, replacement model discovery in the mod vehicle picker. Enhanced resource rejection remains enabled.
- Built-in Vietnamese supplements 816 menu/map labels (79 distinct English texts). Forces the matching American language archive when the bundled translation is active. Still not a complete translation of every label/proper name.
- Save import accepts a folder/ZIP/RAR and imports the first valid SGTA5 save into a free slot, without pc_settings.bin/settings.xml. Existing slots are never overwritten. Manual copying of foreign profile files remains outside that safe import path; no unverified profile offsets are patched.
- Optional Menyoo 1.0.5 package with licenses, 234 supplied dictionary keys translated plus two language names; Vietnamese and plain dictionaries. Disabled by default. Plugin button opens key tray when scripts run, or configuration otherwise. Enable before restarting. User Menyoo configuration is preserved.
- User resolution changes during gameplay apply next startup, avoiding live backbuffer replacement. Original Metal/texture/render algorithms and pinned Xcode 26.2 toolchain are retained.

## Validation and limits
CI uses actual supplied Maybach three-file/ZIP, both Lamborghini Legacy packages, Enhanced rejection, H2R ZIP, Benze55 ZIP, Aquaphobic RAR, and real EngineFiles save. Production compatibility validator is compiled into importer tests, rather than returning stub success. Existing audio conversion, duplicate bank, metadata repair, visual effects and translation tests remain.
No claim of measured FPS gains, on-device Menyoo stability, every model spawning, or every sound playing can be made from importer tests alone. ESign/profile/iOS still determine the real memory allowance. 1.4.7 helicopter camera fixes and unknown per-frame optimizations are not transplanted from a binary without verified source changes.
