# Giao diện tiếng Việt

App mặc định dùng ngôn ngữ vi. Bổ sung bản dịch trong app/App/Localizable.xcstrings; giữ nguyên key và {arg0}, {arg1}… Kiểm tra placeholder bằng tests/test_translation.py. Các thông báo chưa dịch dùng tiếng Anh.
Việt hoá bên trong game là hai resource riêng VietnameseAccented.zip và VietnamesePlain.zip, không phải String Catalog của app.
